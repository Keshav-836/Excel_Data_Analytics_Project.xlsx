
# Excel Data Analytics Project

## About the Project

This project focuses on data analysis using Microsoft Excel. It includes employee data analysis, sales data, Excel formulas, lookup functions, PivotTables, reports, and a dashboard.

The purpose of this project is to practise Excel skills used in data analysis and reporting.

## Tools Used

- Microsoft Excel
- Excel Formulas
- Lookup Functions
- PivotTables
- Charts and Dashboards

## Workbook Contents

- **Staff:** Employee dataset.
- **EMP_TABLE:** Employee data in tabular format.
- **BASIC QUESTIONS:** Excel formula practice.
- **REPORT:** Employee and salary reports.
- **LOOKUP_FUNC:** Lookup function examples.
- **SALES_TABLE:** Sales dataset.
- **PIVOT_TABLES:** PivotTable analysis.
- **Dashbord_Table:** Employee performance data.
- **Dashboard_queries:** Dashboard-related queries.
- **PIVOT_DASHBOARD:** PivotTable summaries.
- **DASHBOARD:** Employee performance dashboard.

## How to Use

1. Download the Excel workbook from this repository.
2. Open `Excel_Data_Analytics_Project.xlsx` in Microsoft Excel.
3. Explore the worksheets to understand the formulas, reports, PivotTables, and dashboard.
