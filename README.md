## 📌 Project Overview

This project demonstrates practical applications of **Microsoft Excel for Data Analytics and Business Intelligence**.

The workbook contains employee and sales datasets, formula-based exercises, lookup functions, PivotTables, summary reports, and dashboard-related worksheets.

The objective is to develop practical Excel skills used by Data Analysts to organise data, answer business questions, calculate key metrics, and present information in a structured format.

## 🎯 Project Objectives

- Analyse employee information and salary-related metrics.
- Perform data calculations using Excel formulas.
- Retrieve information using lookup and reference functions.
- Summarise datasets using PivotTables.
- Prepare reports for employee and sales analysis.
- Organise key metrics for dashboard development.
- Practise Excel techniques relevant to entry-level Data Analyst roles.

## 📈 Key Features

### 1. Employee Data Analysis
- Explore employee attributes and department-level information.
- Analyse salary-related metrics.
- Prepare structured employee reports.

### 2. Excel Formula Practice
- Conditional calculations using `IF` and related functions.
- Aggregation using `SUM`, `AVERAGE`, and `COUNT`.
- Ranking using `RANK.EQ`.
- Dynamic filtering using `FILTER`, where supported.
- Structured references using Excel Tables.

### 3. Lookup Functions
- `XLOOKUP`
- `VLOOKUP`
- `HLOOKUP`
- `INDEX`
- `MATCH`

These functions help retrieve employee or business information from structured datasets.

### 4. Sales Analysis
- Work with product, region, employee, month, quantity, and sales fields.
- Organise sales data for comparison and reporting.
- Prepare summaries to support business analysis.

### 5. PivotTables & Dashboard Preparation
- Aggregate data across categories.
- Summarise employee and sales metrics.
- Organise supporting tables for dashboard development.
- Practise presenting information in a business-friendly format.

## 🚀 How to Use This Project

1. Download the Excel workbook from this repository.
2. Open `Excel_Data_Analytics_Project.xlsx` in Microsoft Excel.
3. Start with `BASIC QUESTIONS` to explore the exercises.
4. Review `EMP_TABLE` and `LOOKUP_FUNC` to understand the lookup and formula work.
5. Explore `SALES_TABLE` and `PIVOT_TABLES` for sales analysis.
6. Review `REPORT`, `PIVOT_DASHBOARD`, and `DASHBOARD` for reporting and dashboard-related work.
7. If the underlying data changes, recalculate formulas and refresh the relevant PivotTables.

**Recommended:** Use the desktop version of Microsoft Excel for the best compatibility with PivotTables and interactive workbook features.
